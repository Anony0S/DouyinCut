## 9. 验收与测试

1. 文件选择、中文 / 空格文件名、本地副本与原文件保留、探测失败提示。
2. 商品必填，默认要求与 60 / 90 秒目标随任务保存，同款前提在 UI 清楚展示。
3. 120 秒分段和尾段正确，多个句子映射源偏移；无句级时间、越界、重复 / 重叠选择明确报错。
4. 只调用 ASR 与文本模型；全量对话完成后统一决策，返回多个时间区间，能去掉价格句并重排卖点。
5. 自动方案与预览衔接；实际 FFmpeg 输出时长、原声、重排和 SRT 映射正确。
6. 保存调整产生新版本，旧预览不误用，未保存调整不能生成剪映草稿，空方案拒绝。
7. 选片失败复用 ASR 缓存重试，不能发布半成品；普通不确定 ASR 提交不能盲目重提。有明确记录的显式退出中断按 ADR 直接重排，已成功步骤仍复用，并单独验证其可能重复执行的边界。
8. 任务恢复、认证 SSE、密钥展示 / 复制、完整安全错误浮层不回归。
9. 超过 20 个项目可分页访问、按名称 / 商品与状态筛选，越界页码合理回收；保存资料后更新排序，重启仍可恢复。
10. 查看项目只显示该源视频及关联结果，同源多个方案完整可选；返回列表保留筛选与页码；未保存片段不被刷新覆盖，切换项目不会串用资料、预览或全量对话。
11. 删除项目 / 方案二次确认；活动任务拒绝删除；项目删除清理本地应用副本与关联数据但不删除外部原视频、云端配置或凭据；方案删除不影响同源其他方案和 ASR 对话，OSS 音频仅由生命周期规则过期。
12. 为已保存修订生成剪映草稿：各区间独立成为视频轨片段；方案字幕成为文字轨中的可编辑文字片段，内容与时间范围正确；工程包含短片素材且不依赖原视频路径；重复任务保护、失败清理、路径和片段 / 字幕数量展示、项目 / 方案删除期间活动任务保护正确；在剪映 11.6.0 实际打开并检查轨道 / 音画 / 字幕位置后方可记录兼容验收通过。
13. 抖音分享短链 / 直播间 URL 可加入监控，监控项持久化并受本地认证；开播触发 FFmpeg 连续录制，内部按需切换 TS 媒体块，直播间列表显示最近检测的开播状态，并按设置自动录制或手动开始录制，结束 / 停止后完成场次收尾；内部媒体块不单独导入为项目，商品片段可导入为普通项目；删除监控或项目不删除录制原文件；直播平台解析和实际音视频由真实直播另行验收。
14. 商品讲解区间与商品片段：首个区间从录制开始、切换时结束上一区间、停止时收尾；录制结束不自动切分；讲解列表包含首次讲解、当前讲解置顶、重复商品按次分开；场次时间线上按商品绘制讲解轨；手动切分可选择位于讲解内且至少 1 秒的自定义起止范围，同一次选区跨内部媒体块仍生成一个视频且切点映射到各块本地时间，不足 1 秒交集被跳过，录制中可先切已封存部分再补切；重复切分不重复生成，活动任务锁定全部源媒体块；跨文件输出的时长与画面顺序正确，音轨缺失与尺寸变化仍可拼接；合成媒体验证同一选区仅一次最终编码，TS 临时重封装不重编码；硬件须实际探测可用，不可用或任务编码失败自动回退受限 CPU，探测缓存与所配置 FFmpeg 隔离，暂停 / 取消不触发回退；失败不发布半成品，临时文件清理并可整次重试；媒体块缺失时部分确认后只切可用来源，全部缺失明确提示；失败保存原因；商品片段可导入并打开项目，源媒体不被修改；切点与直播画面的对应精度由真实录制另行验收。
15. 星斗商品平台：手机号 / 验证码校验、发送成功后倒计时、失败可重试、系统凭据保存与状态恢复、关联范围切换、第一条结果卡片 / 空结果 / 网络与权限失败、无名称禁用、用户确认后单商品添加橱窗、成功后防重复点击、添加失败 / 鉴权失效处理、关闭后的迟到返回不跳转；登录令牌与验证码不进 SQLite / 前端存储 / 日志，`memberTalentId` 不返回前端。真实短信登录、授权搜索与橱窗添加由用户账号单独验收。
16. 商品目录请求：首次获取、成功空目录及跨场次 / 重启复用、不同直播间同 ID 隔离；已知商品和空闲期间无列表请求；未知 ID 合并刷新、60 秒间隔、5 分钟缺失冷却及再次收到消息后重试；消息重连复用目录、目录错误手动刷新且重复请求合并；失败保留目录，不复用上场当前商品，删除场次保留直播间目录，移除监控清除所属目录；不停止录制。
17. 本地设置清理默认只删除到期未引用的产物。勾选扩大范围后，仍按选定天数清理业务记录及文件，确认前显示本次会删除的原视频完整路径。期限内和活动数据依赖受保护，保留设置、凭据及独立剪映工程。验证日期与范围变化需要重新确认、跳过符号链接和目录联接、文件删除失败时保留记录并报告实际释放空间。
18. 达多多商品目录：验证直播间之间的目录隔离、启动与手动同步、分页失败保留上次完整目录、改绑后隔离旧目录，以及导入后按来源直播间当前平台选择参考图能力。真实联调验证仅提供 `ipId` 时每页 50 条请求的实际分页行为和目录范围。
19. 星动力商品平台：验证 token 提交与失败替换、脱敏状态、从签约达人选择并保存 `ipId`、单商品查询展示首条结果，商品列表按直播间搜索、排序和翻页。单商品查询登录失效后返回星动力设置，商品列表提示更新登录后重试。剪映封面参考图使用首条商品的 `productImg`，验证缓存、刷新和本地生图输入；缺图时可上传。Windows 桌面端检查独立窗口的拖动、缩放、复用与关闭，真实凭据、空关键词和多页平台结果另行验收。
20. 直播监控页状态：启动后默认选中排序第一的直播间；切页返回保留手动选择的直播间、历史日期、场次和筛选；切走期间暂停列表同步并关闭临时浮层，返回立即同步。

自动测试使用模拟云端与合成视频；真实服装口播的有效率、误删卖点、字幕偏移、人工修改耗时需用户素材评估。不得承诺固定费用或总完成时间。

## 11. 待验证与后续

优先真实账号验证 120 秒 ASR 输入、多句返回完整性、模型 API 权限与选句效果。若接口只返回单句或 text，不假装完成精确粗剪，保留完整返回帮助诊断。超长输入文本的上下文 / 费用优化待实测，本版不静默截断转写。

剪映 11.6.0 实际打开验证、文本选片退出恢复的冻结桌面验收、Windows 10 / 11 干净标准账户安装和真实覆盖更新仍须按对应记录完成；第三方媒体资源的公开再分发准备见 [§10.3](runtime-release.md#103-验收记录的适用范围)。直播监听的长时间稳定性、消息与媒体时钟误差，以及星斗真实短信登录、授权搜索和橱窗添加仍由真实环境单独验收。

可选转场、智能包装和多款视觉素材池保留在 [长期设计](../../../docs/FUTURE_DESIGN.md)，不阻塞当前单商品 ASR 粗剪闭环。
