## 2. 界面与操作

软件启动默认进入“直播监控”页；根路径及未知路径均跳转直播监控，已有页面的直接链接按对应路由打开。主内容区使用侧栏以外的窗口可用宽度，保留正常左右内边距。直播监控、素材与粗剪、视频项目、后台任务和运行日志随可用宽度扩展。云端设置和本地设置在主内容区内居中并限制宽度。侧栏依次为直播监控、素材与粗剪、视频项目、后台任务、云端设置、本地设置、运行日志。

侧栏底部同排显示本地服务状态图标、版本号和靠右的展开与收起按钮。窗口初始宽度或调整后进入 1100 CSS 像素及以下时自动收起，回到宽窗口时自动展开。用户也可在当前窗口宽度下手动切换。切换时侧栏与主内容区同步过渡，系统启用减少动态效果时立即切换。收起时显示导航图标，悬停或键盘聚焦时在主内容区上方完整显示页面名称。

前端引入 Tailwind CSS 4 与 daisyUI 5，采用 Vite 插件和 CSS-first 配置，不增加 Tailwind 配置文件。daisyUI 默认主题保持浅色，并与现有蓝灰主色、底色和文字色对应。迁移时逐页使用语义组件类；基础 button / input / select / textarea / label 规则置于 Tailwind base 层，使 daisyUI 组件层正常生效。视频项目页的卡片、表格、筛选控件、操作按钮、状态标签与分页已接入；项目筛选工具栏与新建操作同排显示，保留名称双行展示、滚动容器及空状态，鼠标聚焦不显示额外描边，键盘焦点仍可见。直播监控页使用统计、直播间列表、录制时间线、商品讲解轨、讲解列表和商品视频片段卡片；内部媒体分块不作为独立场次卡片展示。

侧栏导航项显示对应图标；底部以单行显示本地服务状态图标和语义版本号，状态说明通过悬停提示提供。主题与窗口偏好见[本地设置](settings.md#本地设置与软件更新)。

全局操作成功 / 失败提示统一使用 daisyUI Toast，固定显示在右上角，最多堆叠 4 条；成功提示 6 秒、错误提示 9 秒自动关闭，并提供手动关闭。与具体内容绑定、需要持续查看或就地处理的诊断 / 字段校验仍显示在所属区域。

输入框、文本域、下拉选择框、单选框、复选框和开关通过自身边框变色显示鼠标及键盘焦点。滑块通过手柄边框变色显示焦点，日期选择器入口在展开时保持强调边框。

### 2.1 视频项目

从侧栏进入“视频项目”页，每个导入的源视频是一个项目，重新粗剪产生的多个方案归入同一项目。列表由后端分页，每页 20 条，按最近活动时间倒序；支持视频名称 / 商品名称搜索和状态筛选，改变筛选回到第一页。返回列表保留搜索条件和页码。

表格限高独立滚动，表头固定，分页控件位于表格外。窄屏搜索栏换行，表格允许内部横向滚动，不撑宽整个页面。

每行首先以上方较大字体显示商品名称，下方以较小的弱化字体显示视频名称；未填写商品名称时显示明确占位。其余列显示源视频时长、处理状态、成片时长、最近更新时间，操作列及其“查看 / 继续编辑”和删除按钮靠右对齐；行内增加留白。列表卡片铺满页面剩余高度，不随条目数量收缩，表头固定、条目在卡片内部滚动，分页位于卡片底部；窄窗口仅表格内部横向滚动。工具栏将搜索与新建视频项目按钮紧邻排列，搜索使用柔和蓝色，新建保留主操作色，窄屏自动换行。成片时长按最新方案的片段时长合计，无方案显示空；“已完成”表示最新方案当前版本已有拼接预览或导出结果，不表示用户已审核。任一相关活动任务优先显示“处理中”，其次为“已暂停”，最近失败 / 取消任务显示相应状态，其他无当前产物的项目显示“待剪辑”。

“新建视频项目”打开系统文件选择器，导入探测完成后自动进入该视频的素材与粗剪。查看项目恢复商品名称、剪辑要求、目标时长、允许偏差和最新方案 / 预览；同源的其他方案仍可选择。编辑页只加载当前源视频及其候选、方案、产物、最近 50 个相关任务（活动 / 暂停优先），最新分析独立返回；全量 ASR 对话按需获取，不加载整个素材库。

商品名称、要求、目标时长和允许偏差保存在项目草稿中，可显式“保存项目设置”；“保存为默认”另外持久化可跨新项目复用的剪辑要求；离开编辑页、打开其他项目、新建视频及提交分析前保存，失败时留在当前页并提示。后台刷新不覆盖输入或未保存的片段调整。返回列表再进入同一项目保留当前会话的片段草稿；片段需通过原“保存调整”按钮持久化，有未保存片段时阻止打开其他项目 / 新建视频。刷新浏览器后的恢复以已保存数据为准。项目切换不会触发云端分析。

### 2.2 素材与粗剪

工作台使用全宽，桌面采用左侧素材 / 商品资料与右侧剪辑区。两个卡片之间提供可拖动分隔条：左侧最小 230px、右侧最小 360px，拖动结束后通过 `PUT /settings/workspace-layout` 随工作目录保存宽度，下次打开及重启应用后恢复（正式版每次启动使用随机回环端口，按来源隔离的 WebView 本地存储无法跨启动保留，因此不使用）；保存失败不影响本次调整；双击或 Enter 恢复默认，方向键每次微调 20px，Shift + 方向键调整 50px，Home / End 调到边界。窗口缩小时自动限制宽度，850px 及以下上下排列并隐藏分隔条。切换页面或卸载时释放拖动捕获。右侧内部并排显示预览列和入选片段，不把全部片段堆在播放器下面。桌面端工作区填满窗口剩余高度，整页不滚动：左侧卡片、预览列和片段列表各自在卡片内滚动，片段列表占满可用高度，保存与生成剪映草稿操作固定在列表下方，不随片段数量向下推移。850px 及以下恢复整页滚动，片段列表限高 560px。

片段卡片紧凑展示编号、源时间范围、时长和两行口播摘要；点击展开可查看完整口播。开始 / 结束输入与上移、下移、移除集中于同一行；片段标题左侧提供拖动手柄，按住拖动可将片段移到任意位置，拖动中以强调色横线标示落点、靠近列表上下边缘时自动滚动，松开后生效，按 Esc 取消；手柄聚焦后可用上 / 下方向键移动一位。拖动排序与上移 / 下移相同，属于未保存的调整；只有一个片段或有操作进行中时手柄禁用。拖动使用指针事件实现，不依赖 HTML 拖放（桌面 WebView 将原生拖放保留给文件拖入）。保持完整文本和原有编辑能力。原素材与拼接成片在预览列顶部左右并排展示；全部粗剪方案在默认展开的方案列表中展示，方案按首次创建时间倒序排列，默认选中最新创建的方案。现存方案从最早创建的方案起编号为 1，按创建顺序递增，“方案序号 · 时长 · 修订号”区分独立方案与其内部修订。点击方案即切换当前预览与片段编辑内容。每项可单独删除；确认后删除该方案的本地预览、导出文件及独占候选 / 商品，保留源视频、ASR 对话及其他方案；活动预览 / 导出任务期间拒绝删除。根据剪辑区实际宽度切换并排 / 上下排列，窄屏切点与操作允许换行，避免水平溢出。

页面顶栏显示返回、视频文件名（只在此处显示一次，附时长与分辨率）、“新建视频项目”和“保存项目设置”。左侧卡片上方为“01 / 商品资料与要求”及全量 ASR 对话，在卡片内滚动；任务状态固定在卡片底部，不随表单滚动：“任务状态”标题固定，其下的任务行限高 168px 单独滚动，最新任务在前，已完成 / 已取消的任务压缩为单行，进行中或失败的任务显示进度条、错误和重试；没有任务时不显示该区块。左侧卡片默认宽 360px（窗口不超过 1450px 时 320px，不超过 1100px 时 260px），用户拖动后以保存的宽度为准。右侧“02 / 预览与调整”的预览列中，原素材 / 源片段播放器与拼接成片播放器左右并排、等高并明确标注，按 9:16 竖屏画面确定预览列宽度（不超过右侧卡片的一半），播放器高度随窗口高度变化；“播放全片”（从头播放完整原素材）位于原素材播放器标题行，方案警告显示在两个播放器下方，其下为粗剪方案列表。成片显示片段数量和总时长，入选片段在旁侧展示源区间。点击播放源片段使用左侧播放器，拼接成片使用右侧播放器。右侧卡片宽度不足时预览列与片段列表上下排列，更窄时两个播放器上下排列。片段卡片的开始 / 结束输入与标签同行，正文字号不小于 12px。浅色模式使用浅灰页面、白面板、深灰侧栏与蓝紫强调色；深色模式使用深色页面和面板、浅色文字，视频使用中性深色背景。

本地播放通过 HttpOnly 会话 Cookie 认证，Cookie 名按服务监听端口隔离；开发版与正式版共享 WebView 配置且同时运行时，不得覆盖彼此的媒体访问凭据。原素材、拼接预览及最终成片继续支持按字节范围读取，不为认证而预先下载完整视频。

点击按钮打开系统文件选择器，替代手动输入路径。浏览器 / Tauri WebView 选中文件后，通过带认证的本地接口流式复制到项目素材目录；原视频不上传云端、不修改原文件。显示文件名、时长、分辨率和本地预览，后台探测完成自动选中新素材。浏览器模式会增加一份本地视频副本。

当前项目的任务状态同时使用文字和颜色区分。完成为绿色，失败为红色，处理中为蓝色，暂停及等待暂停为黄色，排队及取消相关状态使用中性色。进度条使用蓝色表示已完成部分，未完成部分使用主题中性底色。

商品名称必填，剪辑要求可单独“保存为默认”，允许偏差用拖动条设置。表单提供默认关闭的“过滤短语气词”，开启后在同一行显示字数和时长门槛。提交分析后将设置写入任务快照，切换项目恢复默认值。一个分析任务完成 ASR 与文本选片，成功后自动排队 FFmpeg 拼接预览。同一素材已有活动粗剪任务时拒绝重复提交。切换素材应展示该素材的方案和最近填写信息。

逐段展示原话及开始和结束秒数；允许播放源片段、删除、重排、在候选范围内微调切点。至少保留一段。保存调整重建连续时间线和字幕，生成新版本预览；旧预览不能代表调整后的版本。未保存的调整不能生成剪映草稿。

修改商品资料 / 要求后再次分析生成独立方案，保留旧方案，优先复用转写。重复刷新不能污染正在编辑的草稿；草稿与已保存方案独立。

素材与粗剪页的“剪映草稿封面”流程绑定当前视频项目、已保存方案 ID 和方案修订号。用户点击“生成带封面剪映草稿”后打开弹窗。顶部商品标题默认取项目商品名称，可编辑以搜索平台参考图，右侧依次为“获取图片”和“上传图片”。有默认商品名称时自动查询并复用图片缓存，点击“获取图片”用输入框当前值重新搜索和刷新。查询按项目来源直播间当前绑定的平台路由，手动导入视频沿用星斗，星斗图片来自商品详情 `data.images`。星动力使用商品查询首条结果的 `productImg`，下载后用本地参考图预览和生图。平台查询失败、无结果或取图不可用时仍可上传。加载时使用固定比例骨架占位。本地参考图接受 PNG、JPEG 或 WebP（上限 20 MiB），上传后自动选中，并可在重新打开弹窗时选用。删除按钮仅出现在本地上传图上，正在被活动封面或剪映草稿任务使用的图片需等任务结束后删除。弹窗的“生成要求”区域列出当前工作目录保存的多套提示词，打开时默认选中第一套。新增、查看、编辑和删除确认在独立弹窗进行。正文以 Markdown 编辑和预览。首次提供“商品上身效果”默认提示词，可编辑和删除。没有可选提示词时需先新增。提交封面任务时保存所选 Markdown 正文并附加项目商品名称，图片搜索标题独立。默认提示词要求从商品名称提炼中文标题，同时展示人物上身效果图和同款商品单品图。生图直接调用图像模型。封面预览与生成要求在弹窗内左右布局，窄屏自适应堆叠。生成前显示普通空状态；生图中和生成结果图片加载期间仅在对应的固定比例图片框内显示骨架，加载失败显示错误占位，不以骨架遮挡整个弹窗。封面输出 3:4 JPG，分辨率随生图结果而定：生图请求传入 `size=auto` 而不指定像素尺寸，以提示词要求 3:4；返回图已是 3:4 时不裁切，否则保留短边并居中裁切长边，不缩放；无法精确表示 3:4 时按最接近比例取整，重复处理不再裁切；面向抖音商品短视频，强调商品主体、简洁醒目的标题和边缘安全留白。封面生成作为可暂停 / 可恢复的后台 `cover` 任务调用独立的 OpenAI Images API 兼容服务（`/images/edits`、独立 Base URL、模型 ID 和 API Key），生成结果保存在该项目的封面目录并可预览。方案存在未保存片段调整、商品图片无效或封面任务未完成时，不允许生成对应草稿。封面作为剪映草稿列表封面，并以独立 JPG 登记到剪映“素材 → 导入”区，不插入主视频时间线；生成带封面的草稿时总是创建新的草稿目录并保留原有草稿。生成器沿用该 3:4 JPG 的原始像素尺寸，复制到草稿 `Resources/cover/` 并建立独立图片封面子草稿并在主草稿 `cover` 中关联，标记 `type=image`、`sub_type=local`，同时写入 `cover_enable`、根目录 `draft_cover.jpg` 列表缩略图及相对路径 `draft_meta_info.json.draft_cover`，带封面草稿不写入根级 `static_cover_image_path`，也不预先创建不完整的 `Timelines` 目录。后台运行时，对新生成且待补图的带封面草稿，等待剪映创建主时间线索引和工程文件后，向主时间线目录补入缺失的 `draft_cover.jpg`，不覆盖已有文件；应用需保持运行，可能需要关闭并重新打开草稿才能显示。用户已验证 9:16 样本手动补图后可显示并在关闭重开后保留；用户已确认自动补图的缩略图显示；保持原始分辨率的 3:4 封面仍待剪映实机验收，见研究笔记。

星动力参考图按文件头识别 PNG、JPEG 或 WebP，下载时限制 20 MiB。取图失败时弹窗仍显示匹配商品，并提示下载失败、响应为空、格式不支持或超过大小限制；用户可以继续上传本地参考图。

弹窗中“生成要求”与“生成封面”预览左右布局，提示词列表的滚动区与 3:4 封面图片框等高，窄屏下自适应堆叠。提示词卡片默认带淡阴影。悬停未选卡片时整张卡片变色，标题背景透明。选中卡片使用固定底色和“已选”标记。Markdown 编辑区与预览区等高。生成前显示普通空状态；生图中和结果图加载期间只在封面图片框中显示骨架，加载失败显示错误占位。商品参考图仅在各自图片框中显示加载骨架，不以整弹窗骨架遮挡其他信息。

成功生成封面时保留生图服务返回的原图，预览旁提供“查看原图”，以完整画幅显示；原图不可用时提示重新生成。剪映草稿仍使用处理后的 3:4 JPG。

### 2.3 任务与交付

后台任务页使用铺满页面剩余高度的卡片，标题与底栏固定，任务在卡片内部滚动。按创建时间倒序、同时间按任务 ID 倒序稳定排列，每次展示 20 条；接近底部时自动追加下一批，保留“加载更多”按钮用于手动操作。采用创建时间和 ID 组成的游标读取，避免新增任务造成翻页重复或跳项；加载失败保留已有任务并显示“重试加载”，无更多记录时显示已加载全部。状态事件刷新已加载范围，保留列表及可见任务的位置，不回到第一页；进行中数量使用全部任务汇总。每条显示任务类型、状态标签、短 ID、创建时间、进度百分比与进度条，错误详情和原有暂停 / 恢复 / 重试 / 取消操作保留，操作靠右。向下滚动超过 240px 后在底栏显示“回到顶部”，点击滚动当前任务列表，尊重系统减少动态效果的设置。窄屏任务行纵向排列。

任务页展示导入、语音粗剪、预览、导出进度和任务控制。支持持久化暂停 / 恢复、取消、重试；暂停在检查点生效，不能声称立即中断已提交云端请求。

不设置独立“预览与交付”页面，素材与粗剪页也不再提供“确认并导出 MP4”操作和“导出结果”区块：拼接成片即保存修订后自动生成的预览视频，交付通过剪映草稿完成。可从已保存的方案修订生成剪映草稿，路径显示在当前项目任务区。后端的方案审核与 MP4 导出接口保留，当前界面不调用；此前已导出的成片文件仍保留在工作目录 `exports/` 下，页面不再列出。

剪映草稿为独立工程目录，优先写入 `DOUYINCUT_JIANYING_DRAFTS_DIR` 指定位置，否则探测 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft` 或 `%LOCALAPPDATA%\Jianying\User Data\Projects\com.lveditor.draft`。草稿目录名不超过 36 个 ASCII 字符，避免剪映截短目录名后使绝对素材路径失效。每个入选区间先编码成独立视频并复制到草稿 `Resources`，再作为单独时间线片段引用。剪映“素材 → 导入”区登记“原素材 / 源片段”播放器对应的完整项目源文件，每份草稿复制一次。用商品片段建立的项目带上完整商品片段，不复制所属整场录制。入选短片仅用于时间线。方案已有字幕时，每条字幕作为独立、可编辑的普通文字片段写入置顶文字轨，使用白字黑描边、居中下方和自动换行；字幕时间按编码后视频片段的实际时长映射，避免帧级时长差异造成逐段偏移。原生逐字跳动字幕模板当前未接入：必须取得剪映实际下载的模板包及依赖，并按其模板工程结构生成，不能把字幕模板 ID 当作普通花字效果 ID。无字幕方案不创建空文字轨。生成结果记录工程目录、方案修订、视频片段数、字幕条数与成片时长。草稿绑定当前已保存方案 ID 与修订，要求先保存片段调整。带封面草稿把创建时弹窗列出的全部平台及本地参考图、最终封面 JPG 复制进工程并登记为独立素材。该封面实际使用的参考图若仍在当前项目中也会带上，同一参考图只登记一次。封面同时写入封面子草稿及列表缩略图元数据；每次带封面生成均创建新的草稿目录，保留已有草稿。工程文件不随项目 / 方案删除自动清理，因为用户可能已在剪映内继续编辑；相关活动生成任务期间拒绝删除源项目 / 方案。生成采用后台可恢复任务。
