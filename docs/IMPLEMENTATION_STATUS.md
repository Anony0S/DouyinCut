# 开发状态（2026-10-20，0.2.49）

## 当前实现

当前使用前提是**输入视频主要讲同一款商品**，实施基线见 [SPEC.md](../SPEC.md)。

- 点击选择本地视频，流式保存本机副本，后台探测后自动选中；保留原文件与原显示名。
- 默认视频项目页：一个源视频一个项目，每页 20 条后端分页、名称 / 商品搜索、状态筛选和最近活动排序，显示状态及最新方案时长。导入后进入编辑页，查看已有项目恢复保存资料与最新方案，保留同源多方案。
- 新增抖音直播监控页：接受直播间 URL / 分享短链，监控项与场次 / 分段状态存入独立 SQLite 表；单独 Python 进程按 20 秒间隔检测，开播后由 FFmpeg stream-copy 录制为 30 分钟 MPEG-TS 分段，结束或停止监控时封存尾段。
- 每个录制场次使用单条 Python 商品消息 WebSocket。启动后主动查询活动 campaign 初始化当前商品；后续 LiveShopping 商品变化经 LivePop 同 ID 佐证后写入正式事件时间线。商品名称异步查询并关联当前商品与事件，不阻塞消息 ACK；诊断样本不进入生产监听或界面。
- 已封存分段可手动排入现有 import 任务，导入后创建普通视频项目；导入失败可重试，重复提交复用同一任务。监控项删除只移除状态索引，录制文件保留；项目删除不会清理 live 录制目录。
- 抖音解析调用参考 StreamCap 的 `DouyinHandler` 公开适配方式，新增 `streamget>=4.0.10` 依赖并由 uv 管理；链接输入限制在抖音域名。检测异常展示在监控项中，直播流 URL 不落盘。
- 所有页面统一使用侧栏外的窗口可用宽度，移除公共 1800px 最大宽度限制，在 4K 屏幕不再留下大片右侧空白；保留响应式断点与内边距。
- 移除独立“预览与交付”页和侧栏入口；当前编辑页下方展示所属项目的最终 MP4 / SRT 路径、输出目录及可展开播放的历史成片，保留自动拼接预览与确认导出流程，不获取全局成片列表。
- 新增剪映草稿生成功能：针对当前已保存的方案修订，将每个入选区间单独编码为视频并放进剪映草稿 `Resources`，以独立片段放入视频轨道；草稿路径显示在项目任务区。工程媒体不依赖应用导入副本或用户原视频，项目 / 方案删除不自动清理已生成的剪映工程。
- 剪映草稿目录支持 `DOUYINCUT_JIANYING_DRAFTS_DIR` 覆盖，并探测 Windows 常见目录；后台任务重复提交受保护，任务重启时只恢复匹配任务生成的完整工程，失败清理不完整目录。
- 修复剪映打开后草稿目录名被截短、导致素材绝对路径仍指向旧长目录并显示媒体丢失的问题：新草稿目录名限制为短 ASCII 标识，保存前后检查工程引用路径指向草稿内真实素材。
- 剪映草稿新增可编辑字幕文字轨：按方案成片字幕建立独立文字片段，白字黑描边、居中下方、自动换行；按编码后各视频片段的实际时长映射字幕起止，避免帧级时长差异造成累计偏移；任务结果显示视频片段数和字幕数。
- 商品资料 / 剪辑要求独立持久化，可主动保存，离开编辑页 / 提交分析前自动保存；当前编辑页只加载所属素材 / 方案 / 候选 / 产物 / 相关任务，后台刷新不覆盖输入与片段草稿。未保存片段阻止打开其他项目；返回同一项目保留会话内片段调整。
- 任务汇总覆盖所有任务，SSE 发送汇总变化通知；后台刷新不会打断显式打开项目，避免有限全局列表遗漏当前任务。
- 商品名称、可选补充信息、可修改的默认要求，约 60 / 90 秒目标。
- Qwen Audio 原生同步接口，复用模型连接主机 / Key，私有 OSS 临时音频 URL；每段 120 秒、单声道 16kHz WAV，尾段处理，单次等待 300 秒。
- 解析多句句级时间戳并加源偏移；只有整段文本不能精确粗剪，会明确报错。
- 文本模型输入商品资料、要求和完整句级转写，全量转写完成后返回源视频绝对毫秒区间；程序校验连续性、未知 / 重复句、重叠 / 越界并生成候选与时间线。

## 限制与待验证

- 商品变更消息是否在用户目标直播间完整推送、`explain_type` 语义及事件时间与 MPEG-TS 内容的对应精度仍需真实直播验收；自动按商品切分视频暂未启用。
- 真实账号对 120 秒输入的限制、同步长音频是否完整返回词级时间或多个句子，仍需实测；只返回末句等情形不能靠本地模拟证明完整性。
- 语音与文字判断不会验证画面中的上身展示、换款或面料细节；多款混讲不在当前支持前提内。
- 默认以完整句为剪辑单位；同句含价格和有效卖点可能一并排除，句子边界精度、两分钟分段处的口播连贯性需真实素材审核。
- 浏览器文件选择会额外复制本地视频，长视频磁盘与耗时待实测；尚非 Tauri 原生路径对话框。
- 视频项目采用后端分页，编辑页按项目加载；全局任务页仍使用有限列表，极大项目库的查询性能、单项目极多历史成片、长文本上下文和费用统计优化尚需验证。
- OSS 远端对象依赖用户生命周期配置，不自动删除。
- 直播监控依赖第三方抖音解析与 Go 消息桥；平台网页 / 防护或协议变化可能造成检测失败，消息桥要求 Go 1.26.8+。独立 Python 模块已具备离线会话组装和实时探针，但尚无真实直播的成功连接记录，不作为生产连接客户端。真实直播账号、商品切换事件、长时间 30 分钟切段边界、断网 / 休眠恢复和多间并行仍待验收。首版不做主播主页、自动 ASR、断流续录或远程回看。跨款视觉池和字幕编辑延期；剪映工程的真实 11.6.0 打开与音画检查待验收，长期设计见 [FUTURE_DESIGN.md](FUTURE_DESIGN.md)。
- Tauri Python sidecar、生产服务生命周期、Windows 安装包及干净环境验收尚未完成；当前 hash 路由已在浏览器 / 开发 WebView 验证，Tauri 打包后的生命周期仍待验收。

## 环境与运行

FFmpeg / ffprobe、项目 `.venv` Python 3.12、pnpm 及 uv 可用。新增 `streamget` 后已更新 `uv.lock` 并执行 `uv sync`；使用 uv 的用户终端入口为 `uv run python scripts/dev.py`，统一启动器会一并启动 API、普通 worker、直播监控进程和前端。

修改后端后停止原统一启动器，再重新运行并刷新页面；系统已存密钥保留。实际云端和代表性服装素材是下一步验证范围。
