### 2.5 设置与运行日志

#### 云端设置

云端设置以“文本剪辑模型”“语音识别模型”“OSS 存储”“抖音直播登录”“星斗商品平台”页签切换对应配置卡片，不显示步骤编号。切换页签时保留未保存的模型 / OSS 表单与密钥草稿；各卡片独立保存，既不提交其他卡片的未保存内容，也不丢弃其草稿。600px 以下卡片字段单列。工作目录和版本更新位于侧栏“本地设置”页，以列表行排列并在行右侧提供操作；日志在侧栏“运行日志”页查看和清理，本地设置不再提供日志入口。

- 文本剪辑模型：独立配置 Base URL（base_url）、API Key（llm_api_key）、模型 ID（planner_model）和等待时间（chat_timeout_seconds）。
- 封面生图：独立配置 OpenAI Images API 兼容服务 Base URL（image_base_url，包含服务要求的 API 版本前缀但不含 `/images/edits`）、API Key（image_generation_api_key）、模型 ID（image_model）和等待时间（image_timeout_seconds，30–900 秒，默认 240 秒）。该密钥单独保存在 Windows Credential Manager，不与文本或语音密钥回退共用；封面任务使用 multipart `image` 上传本地商品参考图，默认调用 `{image_base_url}/images/edits`，只接受 PNG、JPEG 或 WebP 结果。设置完成只代表配置已保存，不代表真实生图服务可用。
- 模型 Base URL 和模型 ID 不设默认值，首次使用由用户手动填写。保存配置允许未配置的模型字段留空，非空值仍按协议校验；文本、语音和 OSS 卡片可独立保存，不依赖先配置其他卡片。开始分析前检查文本与语音的地址、模型 ID 和密钥是否齐全；测试模型只检查文本配置，不要求语音或 OSS 已配置。
- 语音识别模型：独立配置 Base URL（asr_base_url）、API Key（asr_api_key）、模型 ID（asr_model）和等待时间（asr_timeout_seconds，默认 300 秒，30–900 秒）。语音密钥必须单独保存，不自动复制或回退到文本密钥。支持当前 Qwen 原生多模态音频协议；本流程必须执行 ASR，不保存视觉模型、采样参数或 ASR 开关。
- 文本剪辑模型卡片提供“测试模型”按钮，按当前表单的 Base URL、文本剪辑决策模型、等待时间和替换密钥发起一次简短文本生成请求；替换密钥留空时使用已保存的模型密钥，不回传完整密钥、不保存表单或密钥、不创建业务任务、不上传用户音视频，也不测试 ASR / OSS。界面说明可能产生少量调用费用。仅有效的非空文本回复视为可用，显示所测模型、成功或失败原因及耗时；鉴权、权限、模型 / 接口不存在、限流、云端故障、无效响应和网络错误明确反馈，不返回云端原始响应或凭据。测试等待不超过当前文本等待时间且最多 60 秒，最多输出 128 token，不自动重试；测试中禁用重复点击和文本模型保存，不锁定语音、OSS 或直播登录卡片。模型地址、模型 ID、等待时间或替换密钥变更时清除旧结果，忽略过期结果和页面卸载后的返回。
- 模型设置保存后对新分析和失败任务重试生效；进行中的任务 / 暂停后恢复使用提交时快照。语音 API ID 由用户手动填写，不自动改写或回填。
- OSS 存储：HTTPS endpoint、Bucket、RAM AccessKey ID 和 Secret。卡片底部统一提供“保存 OSS 配置”，一次操作保存 Endpoint、Bucket 和填写的两项访问密钥；密钥留空保留原值，不提供单项密钥保存按钮。临时音频保留策略由 Bucket 生命周期规则管理，建议为 `douyincut/audio/` 前缀设 7 天过期。上传失败的任务详情记录阶段、异常类型及可用的 HTTP 状态和 OSS 错误码，不记录原始异常文本、密钥或签名地址。
- OSS 卡片提供“测试 OSS”，按当前表单的 Endpoint、Bucket 和替换密钥发起一次极小测试对象上传；两项密钥各自留空时使用对应的已保存凭据。对象位于 `douyincut/audio/test-<随机 ID>.txt`，由上述生命周期清理；无需删除权限，不上传用户音视频，不调用模型，不保存表单、密钥或业务任务。使用与正式版后台上传相同的可中断子进程通道，总等待上限 30 秒（超时后终止并回收进程），不自动重试。结果显示成功 / 失败、耗时和经过筛选的 HTTP 状态、OSS 错误码及可操作提示；成功仅证明当前连接与写入权限，不代表 ASR 或签名读取已验证。测试中禁止重复测试和 OSS 保存，其他卡片独立可用；表单变更清除旧结果，忽略过期响应和卸载后的响应。后台音频上传的子进程等待上限为 300 秒，超时记录任务错误详情，避免无限停在 0%。
- 密钥平铺，普通文本输入框默认显示首尾内容与固定五个星号，如 `sk-exa*****1234`。眼睛切换完整值，旁边复制按钮复制完整值或当前替换草稿，成功 / 失败有提示。
- 点击 / 聚焦不清空。替换需全选输入或查看完整值后主动修改；隐藏值部分编辑不能误提交。留空保留旧密钥，展示与替换草稿分离，查看 / 复制不保存。
- 列表设置仅返回配置状态与缩略值；完整值仅通过显式认证接口获取，禁止缓存。保存后立即显示缩略值，使用当前接口返回的密钥显示元数据。
- 抖音直播登录 Cookie 与云端模型 / OSS 设置放在同一设置页，作为本机应用配置保存在 SQLite 配置记录中；普通加载只返回掩码预览，完整值仅通过显式认证接口查看 / 复制。商品监听启动时读取 Cookie 用于建立直播会话及商品详情请求；Cookie 变更对新启动的监听生效。

#### 星斗商品平台

- 未登录时显示“点击登录”，点击打开手机号 / 短信验证码弹窗；勾选平台协议后可发送验证码与登录。发送成功后倒计时 60 秒，发送失败保留原因并允许重试；后端在当前服务会话内同样限制成功发送后的重复请求。登录中禁止重复提交，关闭 / 卸载弹窗清空手机号和验证码草稿。
- 登录后显示脱敏手机号、账号名称、最近验证时间与商品查询范围。查询范围来自平台账号关联的合作 IP，初次默认第一项，多项时可手动切换并持久化。没有合作范围仍视为已登录，但查询提示先在星斗平台确认合作权限；支持重新登录和退出本机登录。
- 登录令牌仅保存在 Windows Credential Manager，不通过本地 API 返回，不进入 SQLite、前端存储或任务载荷；SQLite 仅保存账号 ID、名称、掩码手机号、合作范围、所选范围和最近验证时间。短信验证码不持久化。状态接口读取本机保存状态，不自动请求平台；最近验证时间表示上次登录 / 搜索 / 添加成功时间，不宣称持续在线。
- 商品讲解列表提供“查询商品”；商品名称为空或仅含空白时禁用，提示“暂无商品名称，无法查询”。弹窗以完整商品名称作为初始查询词并自动搜索；用户可编辑 1–200 字符查询词后再次搜索，适用于移除“国补”等标题备注或缩短关键词。每次搜索使用设置中的查询范围，只展示第一条结果，不按商品 ID 回退、不自动补搜、不生成后台业务任务或保存商品资料。
- 结果弹窗以封面、商品名称、店铺、价格及平铺信息展示库存、佣金比例、实时 / 近 30 日 / 累计销量、直播 / AI 直播状态、上架时间及平台商品 ID；上架时间使用平台 `createTime` 原值，完整保留日期和秒级精度，不显示最近讲解时间或活动起止时间。说明只展示第一条，需核对名称 / 规格。商品 ID 存在时提供用户主动确认的“添加橱窗”，成功后显示完成状态并禁用重复点击；添加失败就地显示原因，鉴权失效时关闭弹窗并定向云端设置手动登录。添加请求只接收平台商品 ID，后端使用凭据令牌和当前所选合作范围先读取合作关系取得 `memberTalentId`，再调用星斗 `talentStoreProductAdd`；该临时关联 ID 不落库、不返回前端。星斗成功响应需包含 `data.results` 数组，空数组也表示请求成功。无结果显示空状态，搜索网络 / 权限错误就地提示并允许重试。封面失败显示占位，生产 CSP 仅增加当前平台使用的 p3-aio / p9-aio.ecombdimg.com HTTPS 图片来源。
- 平台搜索成功且分页结果 `total` 为 0 / "0"、显式 `data: null` 时归一为无结果，本地返回 `product: null`，显示“未查询到商品”并保留登录状态；缺失列表字段、非零总数却返回 null、错误列表类型仍按响应格式错误处理。
- 平台 HTTP 401 或明确的未登录 / 登录失效业务响应映射为 `PRODUCT_PLATFORM_AUTH_REQUIRED`，作废本机登录状态并清理保存令牌；前端关闭查询弹窗后跳转 `#/settings?cloudTab=product-platform`，由用户手动登录后重新发起查询。普通权限不足或网络错误保留登录，不自动发送短信或重放查询；关闭弹窗后的迟到响应不触发跳转。
- 后端按平台公开前端实现生成动态签名：加入秒级 timestamp 和 sign_type，按键名排序，保留空字符串、0 与 false，省略 null，追加公开客户端常量后计算大写 MD5；GET 使用查询参数，POST 使用 JSON，认证请求带 access-token 查询参数及 member-token 头。对外请求最多等待 15 秒，不自动重试。异常不回传请求 URL，HTTPX 日志移除该平台 URL 查询串，平台错误文案隐藏提交的手机号、验证码、令牌和签名。
- 完整真实账号短信登录与授权商品搜索需单独验收；签名已与所提供 HAR 中的 12 条请求全部匹配，无令牌真实搜索已确认返回业务 401。实现与证据边界见 [.scratch/product-platform/spec.md](../../../.scratch/product-platform/spec.md)。

#### 本地设置与软件更新

本地设置的工作目录行提供“打开目录”和“更换目录”按钮。“打开目录”通过已认证的 `POST /api/v1/settings/work-directory/open` 在 Windows 文件管理器打开后台当前使用的工作目录，无需重启；目录不存在或打开失败时显示原因。本地设置的目录重置与重启、版本检查命令同时授权开发主窗口 `main` 和生产工作台 `workbench`；权限匹配仅限本地页面及 `127.0.0.1` 回环来源。

本地设置提供手动软件更新，更新源固定为公开仓库 `Anony0S/DouyinCut` 的 GitHub Releases 最新正式版，不在启动时自动联网或下载。按三段式版本号比较，仅更新到更高版本；正式版标签使用 `v<规格版本>`，必须同时附带 `DouyinCut-<版本>-setup.exe` 与同名 `.exe.sha256` 文件。原生层仅接受官方仓库该版本的 HTTPS 附件地址及 GitHub 附件重定向，限制响应和安装包大小，下载到独立应用缓存，校验声明长度和 SHA-256；失败或取消时不执行安装。校验文件用于传输完整性检查，信任来源为 GitHub 仓库和 HTTPS，尚不具备独立发布者签名。下载显示进度、允许取消；切换页面后后台继续下载，应用退出后不续传，重新下载覆盖专用缓存。

用户明确选择“退出并安装”后，先处理未保存草稿，查询活动任务并再次确认；录制中或有录制请求时拒绝更新安装，要求先停止录制。退出前再次检查录制，无法读取保护状态时保留应用。确认后安装包再次校验，通过原有 DesktopSession 安全退出；安装器等待旧应用进程结束后再开始交互式覆盖安装，不强制终止应用，不删除工作数据、原视频、配置或凭据。退出 / 安装失败展示原因；开发桌面模式允许检查与下载，安装仅限 Windows x64 生产桌面会话。使用当前格式，不增加历史数据迁移。发布方法及实际覆盖安装验收边界见 [软件更新](../../../docs/software-updates.md)。

#### 运行日志

- 侧栏“运行日志”页（`#/logs`）集中查看两类日志：应用运行日志 `desktop-runtime.log`（及轮转保留的上一份 `desktop-runtime.previous.log`），以及工作目录 `logs/` 下各任务的 FFmpeg 输出。左侧列出非空日志文件：应用运行日志在前，任务日志按所属后台任务或商品片段分组并显示任务类型 / 商品名称，按修改时间倒序；已删除任务的日志归入“已删除的任务”。默认打开应用运行日志。
- 右侧以等宽文本显示所选文件末尾最多 512 KB，超出时提示仅显示末尾部分。支持关键字搜索（不区分大小写）与“只看错误”（仅应用运行日志提供；traceback 等续行沿用所属记录的级别，旧格式中的 `ERROR` / `Traceback` 行同样识别），显示匹配行数；“复制”复制当前筛选后的内容，“在文件夹中显示”在资源管理器中选中该文件。
- “自动跟随”默认开启：窗口可见时每 3 秒按字节偏移只读取新增内容，窗口隐藏时暂停；阅读位置不在末尾时新增内容不滚动视图；页面内最多保留约 100 万字符，超出时丢弃最早的整行。文件被清空或替换后从新内容末尾重新读取。读取失败在原位置显示原因，不清空列表。
- “清理日志”经锚定确认后执行：清空应用运行日志（文件被运行中的进程占用，原位截断而非删除）、删除上一份运行日志，并删除工作目录中的任务日志；仍有活动任务（queued / running / pause_requested / paused / cancel_requested）或处于生成中的商品片段，其日志保留。结果提示清空 / 删除 / 保留数量。
- 应用各进程（api / worker / live_monitor）统一输出 `YYYY-MM-DD HH:MM:SS 级别 [角色] 记录器: 消息`，以 UTF-8 写入；应用自身记录保留 INFO 及以上，第三方库只保留 WARNING 及以上，避免请求地址进入日志。安装版由原生外壳将运行时 stderr 追加到定位配置同级 `logs/desktop-runtime.log`，启动时超过 5 MB 则改名保留为上一份；开发启动器将各进程日志同时写入 `data/runtime-logs/desktop-runtime.log` 并按相同规则轮转。统一格式之前写入的内容按原文显示。媒体进程没有输出时不再生成空的任务日志文件，并删除同名旧文件。
