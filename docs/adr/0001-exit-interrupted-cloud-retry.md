# 显式退出时中断云端请求并允许直接重发

为避免模型响应耗时让桌面应用长时间无法退出，用户选择显式退出时不等待云端响应，录制与其他本地工作仍完成安全收尾；退出中断请求下次执行时直接重发，不要求先核查云端或另行确认，已保存的成功结果继续复用。相较等待响应或阻止未知结果重试，该选择优先保证退出速度与后续操作便利，但本地断开无法撤销已经到达云端的请求，可能造成重复执行和额外费用。此决定只适用于有明确退出原因的请求，不作为清空成功缓存、放行一般网络异常重试或兼容历史业务格式的依据；整体实施方案及启动时重新排队范围见已发布的 [Windows 打包规格](../../.scratch/windows-packaging/spec.md)。
